Faça backup da pasta ativa fora de mods. Extraia a pasta herdr-music do ZIP para mods dentro de HERDR_APP_HOME, substituindo a instalação inteira.

No Spotify Dashboard cadastre exatamente http://127.0.0.1:8765/callback. Clique em Conectar Spotify, informe o Client ID e autorize no navegador. Cole o endereço final completo no painel mesmo se a página de retorno não carregar. Clique em Copiar código de desbloqueio, guarde o código e clique em Concluir conexão. Para escolher sua própria senha, use Usar minha senha. Inicie uma faixa em um dispositivo Spotify para testar os controles.
